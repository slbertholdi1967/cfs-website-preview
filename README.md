# CFS Designs US - new website (preview)

Static preview of the new www.cfsdesignsus.com, published with GitHub Pages at https://preview.cfsdesignsus.com
for the board to review. It does not touch the live Squarespace site or the CFS apps.

- Pages are generated by `python3 build.py` from `data/projects.json` (42 portfolio projects, texts and photos copied
  from the current website). Edit the data or `build.py`, run the build, commit.
- `css/site.css`, `js/site.js`: styles and small interactions (no frameworks, no tracking, no cookies).
- Every page has `noindex, nofollow` and `robots.txt` blocks search engines: the preview is not public on Google.
- The quote form and the delivery tracking are DEMOS with example data: nothing is sent and no CFS system is called.
- `CNAME` holds the custom domain (preview.cfsdesignsus.com).
